# Qiskit Fall Fest GDL 2026

A minimalist landing page for Qiskit Fall Fest Guadalajara 2026.

## GitHub Pages Setup Instructions

Follow these steps to publish this page on GitHub Pages:

### 1. Create a GitHub Repository

```bash
# Make sure you're in the project directory
cd qiskit_fall_fest_gdl

# Add all files
git add .

# Commit the files
git commit -m "Initial commit: Add landing page"

# Create a new repository on GitHub (via web interface or CLI)
# Then add the remote and push
git remote add origin https://github.com/YOUR_USERNAME/qiskit_fall_fest_gdl.git
git branch -M main
git push -u origin main
```

### 2. Enable GitHub Pages

1. Go to your repository on GitHub
2. Click on **Settings** (top right)
3. Scroll down to **Pages** section (left sidebar)
4. Under **Source**, select:
   - Branch: `main`
   - Folder: `/ (root)`
5. Click **Save**

### 3. Access Your Site

After a few minutes, your site will be available at:
```
https://YOUR_USERNAME.github.io/qiskit_fall_fest_gdl/
```

GitHub will show you the exact URL in the Pages settings once it's deployed.

## Local Development

To view the page locally, simply open `index.html` in your web browser.
